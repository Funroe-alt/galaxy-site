Get started

From download to playing in a minute

The Galaxy Launcher sets everything up for you and keeps Galaxy up to date.

  1. Install the launcher

    Download it from GitHub and run the installer. Windows may ask you to confirm because it's a new app.

  2. Sign in with Microsoft

    You sign in on Microsoft's own page. Galaxy never sees your password.

Questions

FAQ

Can I use Galaxy on servers?

Galaxy has no combat automation, ESP or X-ray, so it's meant for normal play. Some servers still limit client mods or features like FreeLook and FullBright, so check each server's rules before you join.

Why does Galaxy need OpenGL?

Minecraft 26.2 uses Vulkan by default. Galaxy's menu and HUD draw with OpenGL, so the launcher sets Graphics API to OpenGL. You can also change it in Options → Video Settings.

Is it free?

Yes. Galaxy is free and the source code is on GitHub.

Is my account safe?

Sign-in goes through Microsoft directly. The launcher only stores the sign-in token Microsoft gives it, on your own PC, so you stay signed in.

Does it work with other mods?

Galaxy is a Fabric mod, so most Fabric mods for 26.2 work alongside it. Add them to the Galaxy profile in the launcher.
